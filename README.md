# Iviart · Tour 360°

Prévia de revisão das unidades Maringá e Curitiba. Projeto visual em alinhamento, sem aprovação final.

Player exportado do Pano2VR 7.1.11; interface HTML/CSS e controles JavaScript. 31 panoramas de Maringá e 36 de Curitiba. Fotografias, marca e contatos da Iviart. Layout por MG Tour.

A publicação usa GitHub Pages a partir da branch main, pasta raiz, com .nojekyll. Manter todos os arquivos, incluindo tiles, imagens e XML.

Testes físicos de Safari/iOS 18 e Chrome/Android ainda pendentes. Internet Explorer tem alternativa com contatos.
